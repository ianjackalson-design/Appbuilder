## 🎯 交互流程示例

### 流程 1: 创建任务完整流程
```
用户操作                    系统响应
   │
   ├─→ 点击 Tasks Tab  ──→  切换到任务页面
   │
   ├─→ 点击 New Task   ──→  打开创建对话框
   │
   ├─→ 填写任务信息    ──→  实时验证输入
   │
   ├─→ 点击 Create     ──→  调用 TaskContext
   │                          │
   │                          ├─→ 生成 ID
   │                          │
   │                          ├─→ 添加到列表
   │                          │
   │                          └─→ 显示 Toast
   │
   └─→ 查看任务列表    ──→  按优先级显示
```

### 流程 2: AI 对话流程
```
用户操作                    系统响应
   │
   ├─→ 开启 AI 开关    ──→  启用 AI 服务
   │
   ├─→ 输入消息       ──→  添加到对话历史
   │
   ├─→ 点击发送       ──→  ChatContext 处理
   │                          │
   │                          ├─→ 检查 AI 状态
   │                          │
   │                          ├─→ 调用 aiService
   │                          │      │
   │                          │      ├─→ 发送到 API
   │                          │      │
   │                          │      └─→ 获取响应
   │                          │
   │                          └─→ 显示 AI 回复
   │
   └─→ 查看对话       ──→  完整对话历史
```

### 流程 3: 语音命令流程
```
用户操作                    系统响应
   │
   ├─→ 点击麦克风     ──→  启动语音识别
   │                          │
   │                          └─→ 显示 "聆听中"
   │
   ├─→ 说话          ──→  实时转写文本
   │
   ├─→ 停止说话       ──→  处理最终结果
   │                          │
   │                          ├─→ 分析命令类型
   │                          │
   │                          ├─→ 保存到历史
   │                          │
   │                          └─→ 执行对应操作
   │
   └─→ 查看历史       ──→  显示命令记录
```
